# CraftCon - Cosplay Planner

A personal planning tool for cosplayers to organize their projects, materials, budgets, and timelines.

## Features

- ✨ Project planning dashboard
- 📂 Track multiple cosplay projects
- 💰 Budget tracking per project
- 📅 Timeline and deadline management
- 🎨 Material and color planning
- 📌 Quick notes and brainstorming

## Getting Started

1. Register for an account
2. Create your first cosplay project
3. Break down the costume into parts
4. Track materials, budget, and progress

## Tech Stack

- HTML5
- CSS3 (with CSS variables)
- Vanilla JavaScript
- LocalStorage for data persistence
